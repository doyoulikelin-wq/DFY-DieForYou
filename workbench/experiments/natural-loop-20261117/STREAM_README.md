# Log / Streaming 回放说明

## 使用

打开natural-test.html，默认进入Log / Streaming。选择轮次后，可播放、暂停、选择1×/5×/20×、下一事件、拖动时间轴或到结尾。左侧仅显示真实用户输入与已通过本地发送检查的回复。右侧保留内部候选、游戏状态更新、偏好、规划、反思和记忆记录；每项均可展开完整payload与原始JSONL行。

## 真实性

93条原始记录中，91条按精确ID关联到轮次，2条为全局起止记录。没有token delta或SSE分块，页面不会用打字动画补造。计时是协调器记录时间，不是模型内部开始时间或客户端已呈现时间。任务数量冲突后的刷新处理不制造第二条用户输入；状态失效候选不会先进入交付窗口再被撤回；后台空档原样保留。

纳秒时间在结构化前端数据中用十进制字符串表示；原始JSONL另外保留raw_line，下载逐字节保持原始行，避免JS大整数精度丢失。模块日志也已改为按结构化ID匹配，替代原先字符串子串匹配。

## 验证

7项回放数据测试通过。浏览器已验证播放、暂停、20倍速度、时间轴、切轮取消、候选不提前交付、偏好变更显示、日志展开、原始JSONL下载。浏览器下载文件与对应7条源日志逐字节一致。没有做手机实机测试。
